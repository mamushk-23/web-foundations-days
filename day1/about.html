About QuickNotes

QuickNotes is a lightweight note-taking app for capturing ideas the moment they happen. It keeps things simple so you can write, organize, and find your notes without any friction.

How to use QuickNotes

  1. Open QuickNotes and press N to start a new note.
  2. Type your note and add tags to group related ideas.
  3. Use the search bar to find any note by keyword or tag.

Features

  • Instant note capture with autosave
  • Tags and folders for organization
  • Full-text search across all notes
  • Dark mode and keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + K Open search
